
# 💻 TecnoShop RD | Tienda Informática

## 📌 Descripción
TecnoShop RD es una página web dedicada a la venta de productos informáticos y tecnológicos. Permite a los usuarios visualizar productos, consultar precios y realizar pedidos mediante WhatsApp.

## 🚀 Tecnologías utilizadas
- HTML5: Estructura de la página.
- CSS3: Diseño y estilos visuales.
- JavaScript: Funcionalidades e interacción con el usuario.

## 🛒 Productos disponibles
- Laptop profesional.
- Mouse inalámbrico.
- Teclado mecánico.
- Monitor HD.

## ✨ Características
- Página de inicio.
- Catálogo de productos.
- Imágenes y precios.
- Sección de ofertas especiales.
- Botones de compra.
- Integración con WhatsApp.
- Diseño adaptable a dispositivos móviles.
- Navegación entre secciones.

## 📂 Estructura del proyecto

```text
TecnoShop-RD/
│

```

## ⚙️ Instalación y ejecución
1. Descargar el proyecto.
2. Abrir la carpeta TecnoShop-RD.
3. Abrir el archivo index.html en un navegador web.
4. Explorar los productos y probar los botones de compra.

## 📲 Sistema de compras
Al presionar el botón Comprar, se genera automáticamente un mensaje con el nombre del producto seleccionado y se abre WhatsApp para contactar con la tienda.

## 🎨 Diseño
La página utiliza una combinación de azul oscuro, azul brillante, blanco y gris claro para ofrecer una apariencia moderna y profesional.
